Tentang Saya

Saya Ravael, siswa Rekayasa Perangkat Lunak dengan pengalaman praktik langsung di bidang web development dan IT technical support.

Saya terbiasa mengembangkan website dan aplikasi mobile dengan Laravel, React JS, dan Flutter, serta mengelola sistem operasional berbasis Odoo 17. Di sisi infrastruktur, saya menangani instalasi, pemeliharaan perangkat keras komputer, jaringan kantor (LAN & Wi-Fi), dan operasional sistem IT perusahaan.

Kemampuan komunikasi, kepemimpinan, dan kolaborasi tim saya kembangkan lewat pengalaman organisasi dan lingkungan kerja profesional, dari Ketua OSIS sampai ruang kerja kantor industri.

Di luar itu, saya juga memproduksi dan mengelola konten digital untuk YouTube dan media sosial perusahaan.
